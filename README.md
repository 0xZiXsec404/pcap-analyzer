# PCAP-Analyzer

Учебный анализатор сетевого трафика на чистом Python — без Scapy и сторонних парсеров.
Разбирает IPv4/TCP/UDP/ICMP-заголовки вручную, побайтово, и умеет ловить живой трафик
прямо с сетевого интерфейса через raw sockets.

## Возможности

- Разбор заголовков **IPv4**, **TCP**, **UDP**, **ICMP** напрямую из сырых байт
- Живой захват трафика через raw socket (`AF_INET` + `SOCK_RAW`, Windows)
- Фильтрация пакетов по протоколу, порту назначения, IP назначения
- Человекочитаемый вывод в духе Wireshark
- Проверка принадлежности IP подсети (`ip_in_subnet`)
- Hex + ASCII дамп payload (`hex_ascii_dump`)

## Структура проекта

| Файл | Назначение |
|---|---|
| `io_utils.py` | чтение hex-файла с тестовыми пакетами |
| `ip_parser.py` | разбор IPv4-заголовка |
| `tcp_parser.py` | класс `TCPHeader` — разбор TCP-заголовка, флаги |
| `udp_parser.py` | класс `UDPHeader` — разбор UDP-заголовка |
| `icmp_parser.py` | класс `ICMPHeader` — разбор ICMP-заголовка |
| `dispatcher.py` | определяет протокол и вызывает нужный парсер |
| `format_packet.py` | форматирует разобранный пакет для вывода |
| `filter_packet.py` | ввод и применение фильтра (протокол/порт/IP) |
| `subnet.py` | проверка принадлежности IP подсети |
| `ascii_dump.py` | hex+ASCII представление payload |
| `main.py` | точка входа: захват трафика, фильтрация, вывод |

## Запуск

Требует **Windows** и терминал, запущенный **от имени администратора**
(raw socket на уровне ОС требует повышенных прав).

```bash
python main.py
```

Программа спросит фильтр (протокол/порт/IP — можно оставить пустым, чтобы
не фильтровать) и начнёт выводить пакеты в реальном времени. Остановка — `Ctrl+C`.

## Пример вывода

```
10.100.221.232 -> 172.217.115.4 TCP ['PSH', 'ACK'] src_port=58491 dst_port=443
10.100.221.232 -> 8.8.8.8 UDP 61 src_port=65302 dst_port=53
```

## В планах

- Статистика по завершении захвата (топ портов/протоколов)
- Экспорт в реальный `.pcap` формат (через `scapy.utils.wrpcap`)
- Фильтрация по src IP/порту (сейчас только по dst)
- CLI-аргументы вместо интерактивного ввода
